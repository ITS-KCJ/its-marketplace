# Política de Segurança

Repositório privado de uso interno (ou template/base). Não há programa público de bug bounty.

## Como reportar uma vulnerabilidade

Se encontrar uma vulnerabilidade de segurança neste projeto, entre em contato direto com o mantenedor antes de abrir uma issue pública.

Contato: jucebueno@gmail.com

Inclua na mensagem:
- Descrição do problema
- Passos para reproduzir
- Impacto potencial

Resposta inicial em até 5 dias úteis.

## Dependências

Este repositório usa Dependabot para alertas e atualização de dependências com vulnerabilidades conhecidas.
